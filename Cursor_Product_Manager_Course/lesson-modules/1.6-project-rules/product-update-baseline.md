# Product Update: Workspace Sharing Feature

We're excited to announce a new feature that will help teams collaborate more effectively.

## What is Workspace Sharing?

Workspace Sharing allows you to share your projects with external collaborators. This feature enables teams to work together across organizations and invite stakeholders to view and contribute to project work.

## Key Features

- Share projects with external users
- Control access levels (view-only or edit permissions)
- Invite collaborators via email
- Track who has access to each project
- Revoke access at any time

## How It Works

1. Navigate to your project settings
2. Click "Share Project"
3. Enter email addresses of collaborators
4. Set permission levels
5. Send invitations

## Benefits

This feature helps teams:
- Collaborate with external partners
- Share project status with stakeholders
- Work with contractors and freelancers
- Coordinate across multiple organizations

## Availability

Workspace Sharing is now available for all Pro and Enterprise plans. Free plan users can upgrade to access this feature.

## Getting Started

To start sharing your projects, go to any project and click the "Share" button in the top right corner.

For more information, check out our documentation or contact support.
